# Проектирование современных информационных систем: учебные материалы

Репозиторий содержит программные материалы и примеры инженерных решений, использующихся при проектировании современных web-приложений
Материалы ориентированы на студентов 1,2 курса магистратуры направления «Механика и цифровое производство" СПбПУ
 
## Технологический стек
*   **Языки:** Python, SQL
*   **Библиотеки и фреймворки:** Jupyter Notebook

## Программные решения и технологии
- **Базы данных:** Postgres, NoSQL: Redis, Cassandra, MongoDb, neo4j
- **Брокеры сообщений:** RabbitMQ, Kafka
- **Журналирование, аудит, мониторинг:** Prometheus, Grafana, ELK
- **Безопасность**: Аутентификация, авторизация, подпись
- **APIGateway**: Балансировка, Rate Limit
