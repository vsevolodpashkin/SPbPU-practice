
## ЗАДАНИЕ

1.  Разработать мета-модель Системы
- бизнес-цели, которая может преследовать организация при разработке Системы (используем критерии SMART, min 3 шт)
- список стейкхолдеров и их интересы
- контекстная диаграмма (L1 по нотации С4)

2.  Подготовить описание основных компонентов Системы и архитектурных решений

- диаграмма компонентов Системы (L2 по нотации С4)
- способы интеграции между компонентнами системы (rpc/messaging, список программных интерфейсов, описание контрактов взаимодействия)
- связь ФТ, НФТ и выбранных архитектурных решений

3. Описать Happy Path одного из сценария работы Системы
- разработать Sequence диаграмму процесса

4.  Для программных интерфейсов Системы разработать спецификацию 
- в формате OpenAPI (min 3 шт)

5.  Разработать модель данных для выбранной Системы
- Entity Realtionship диаграмма
